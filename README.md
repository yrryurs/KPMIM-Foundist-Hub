# KPMIM-Foundist-Hub

## About the Project
KPMIM Foundist Hub is a web-based lost and found management system developed to help students report and track lost items within the college.
The system makes it easier for users to submit reports, browse found items, and manage lost and found records in one place.

## Features
* Lost item reporting
* Found item reporting
* Item tracking and management
* Search functionality
* User-friendly dashboard

## Technologies Used
* HTML
* CSS
* JavaScript
* Laravel
* MySQL
